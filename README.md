# codex-notes

Codex와 함께 작업할 때 참고할 공통 작업 정책과 기본 선호를 관리하는 저장소입니다. 여러 프로젝트가 이 저장소의 정책 문서를 직접 참조하여, 정책을 프로젝트마다 복사하고 갱신하는 부담을 줄입니다.

공유 정책은 기본 선호입니다. 사용자의 현재 명시적 요청과 해당 작업에 적용되는 프로젝트 지침을 우선하며, 별도 지침이 없는 사항에 공유 정책을 적용합니다.

## 정책 문서

- [r-rmd-coding-policy.md](r-rmd-coding-policy.md): R code, R Markdown, R Notebook 작업 기준

## 프로젝트에서 참조하기

각 R 프로젝트의 `AGENTS.md`에 아래 내용을 추가합니다. 이 저장소에는 별도의 `AGENTS.md`를 두지 않고, 프로젝트에서 정책 문서를 직접 참조합니다.

```markdown
## Shared Codex Notes

R 또는 R Markdown 작업을 시작하기 전에 다음 공유 정책 문서를 열어 전체 내용을 읽고 기본 작업 기준으로 적용한다.

- https://raw.githubusercontent.com/gglee4ai/codex-notes/main/r-rmd-coding-policy.md

공유 정책은 문서를 읽는 시점의 `main` 브랜치 내용을 기준으로 한다. 정책 갱신을 안내받으면 다시 읽는다.
박사님의 현재 명시적 요청과 해당 작업에 적용되는 프로젝트 지침을 우선하고, 별도 지침이 없는 사항에 공유 정책을 적용한다.
공유 정책에 접근하지 못한 경우에는 내용을 알고 있다고 가정하지 말고, 접근하지 못했음을 박사님께 알린다.
```

공유 정책의 변경은 GitHub의 `main` 브랜치에 반영된 뒤, 각 프로젝트에서 문서를 다시 읽을 때 적용됩니다. 로컬 수정만으로는 Raw URL의 내용이 바뀌지 않습니다. 이미 진행 중인 작업에 변경 사항이 자동으로 전달되는 것은 아니므로, 필요한 경우 정책을 다시 읽도록 요청합니다.

## 관리 원칙

- 기존 문서의 파일명과 경로는 외부 참조에 사용되므로 유지합니다. 변경이 필요하면 참조하는 프로젝트의 링크도 함께 점검합니다.
- 공통 정책만 이 저장소에서 관리하고, 프로젝트별 예외는 각 프로젝트의 `AGENTS.md`에 기록합니다.
- 정책 수정 시 기존 내용과 중복되거나 충돌하는 지침이 생기지 않도록 확인합니다.
- 공개 저장소이므로 비공개 연구 자료, 인증 정보, 개인 환경의 민감한 정보는 포함하지 않습니다.
